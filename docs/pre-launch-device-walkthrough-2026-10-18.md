## 走查中事故记录

### 2026-10-18 18:00-18:40 生产代理全线 503（已解决）

- **现象**：走查 §1 建待办时 App 报「AI server is unstable」（客户端熔断文案，行为正确、原文已存未丢话）
- **根因**：Z.AI 对老 key 持续 429（限流），两个 ZAI provider 熔断全开；CLAWTO_OPENAI 兜底 404 挂了六周（连败 1925），无可用兜底 → 全线 503
- **处置**：`wrangler secret put PROVIDER_KEY_ZAI_ANTHROPIC`（一把 secret 管两个 ZAI provider）换新 key → 冷却期过后 half-open 试探成功 → 熔断自愈，无需重启/部署。`/v1/health` 200，AIR closed 0 连败
- **诊断路径**：`/v1/health`（503 down）→ `GET /v1/admin/providers`（X-Admin-Token，权威熔断态）→ 本机直连 Z.AI 对照（200，排除 IP 限流）→ 冷却后重试成功
- **遗留**：①CLAWTO_OPENAI 404 尸体修/禁用待拍板；②层 B/C 告警（Telegram/healthchecks）此次是否触发待核实——挂了数小时才发现；③ZAI_ANTHROPIC 仍 half-open，下次试探自愈属预期
